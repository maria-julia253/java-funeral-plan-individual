# java-funeral-plan-individual

  > About the Project:

  Java program that calculates the monthly fee for an individual funeral plan, considering the amount of dependents and their ages.
  The system has a fixed monthly fee of R$49,90, plus an individual fee upon each individual dependent, according to their age.

  > Features:

  - Monthly fee calculation;
  - Fee attribution according to dependent age;
  - Age validation - dependents aged 0 or below aren't allowed. The system requires a new entry in the event of an incorrect input.
