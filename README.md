# java-funeral-plan-individual

  > About the Project:

  Java program that calculates the monthly fee for an individual funeral plan, considering the amount of dependents and their ages.
  The system has a fixed monthly fee of R$49,90, plus an individual fee upon each individual dependent, according to their age.

  > Features:
  - Monthly fee calculation.
  - Fee attribution according to dependent age.
  - Monetary values formatting.
  - Age validation - dependents aged 0 or below aren't allowed. The system requires a new entry in the event of an incorrect input.
  - Registration of the names and ages of the dependents.

  > Featured technologies: 
  - Java;
  - Scanner;
  - Repetition structures;
  - Conditional structures;
  - Aritimetic operators;
  - Exit formatting with printf.

  > Calculation rules:
  - Fixed monthly fee: R$49,90.
  - Fee for dependents up to 64 years of age: R$5,00.
  - Fee for dependents over 64 years of age: R$15,00.

   -> Monthly fee = 49.90 + the sum of the individual dependent fees.

   > Educational goal: 
 
   This project was executed with the goal of practicing fundamental concepts of the java language,especially repetition and conditional structures, input validation and aritimetic operations.
